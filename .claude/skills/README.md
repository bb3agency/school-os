# Project skills

Design-engineering skills by Emil Kowalski, copied from https://github.com/emilkowalski/skills
at commit d16ebe60d09a5ba2afcb7054ede9d0a10c9f6128 (MIT, see LICENSE-emilkowalski-skills).
Only the web-relevant skills are included (the Expo, native mobile and Swift ones are left out).

They are guidance for AI coding sessions. CLAUDE.md and docs/17-ui-design-system.md win on any
conflict: WCAG 2.2 AA, Baseline Widely Available features, prefers-reduced-motion, CSP (no inline
styles), self-hosted fonts, and no new dependency without the licence/maintenance/CVE check.
Library suggestions in pick-ui-library are options to evaluate, not approvals.
