## Domain (Indian schools, Andhra Pradesh)

| Term | Meaning |
|---|---|
| **Admission & Withdrawal Register** | The school's permanent register of every student's admission and leaving details; the legal anchor for identity fields in SchoolOS (BR-01) |
| **Admission number** | School-assigned identifier in the admission register; not used as SchoolOS's internal ID |
| **Aadhaar (as printed)** | Name, DOB and gender exactly as printed on the Aadhaar card; SchoolOS stores these and the last 4 digits only, never the full number |
| **APAAR ID** | Automated Permanent Academic Account Registry: a lifelong student academic ID generated by schools via UDISE+ using Aadhaar-verified details; generation fails when names/DOB don't match Aadhaar; required for exams like NEET and CUET |
| **AP Child Info** | Andhra Pradesh's state student information portal (student movement, TCs, dropout status) |
| **Bonafide certificate** | Certificate confirming a student studies at the school (for scholarships, passes, ID updates) |
| **CAREERS portal** | CISCE's online system where schools register and confirm ICSE/ISC candidates |
| **CBSE / BSE AP / CISCE** | Boards: Central Board of Secondary Education · Board of Secondary Education, Andhra Pradesh (SSC) · Council for the Indian School Certificate Examinations (ICSE Class 10, ISC Class 12) |
| **Correspondent** | School management representative, typically the owner/trustee's executive; the economic buyer |
| **DEO** | District Educational Officer; issues circulars and instructions to schools |
| **Nominal roll** | List of candidates submitted to a board for exams; errors propagate to admit cards and certificates |
| **RTE (25% quota)** | Right to Education Act seats for economically weaker sections in private unaided schools (not applicable to minority institutions) |
| **SSC** | Secondary School Certificate (Class 10, state board) |
| **Talliki Vandanam** | AP scheme paying mothers per school-going child, with eligibility and attendance conditions; drives parent queries at school counters |
| **TC (Transfer Certificate)** | Certificate issued when a student leaves; required for admission elsewhere |
| **UDISE+** | Unified District Information System for Education Plus: national school and student-level database updated annually by schools |

## Privacy and compliance

| Term | Meaning |
|---|---|
| **DPDP Act / Rules** | Digital Personal Data Protection Act 2023 and Rules 2025 (India) |
| **Data Fiduciary** | Entity deciding purposes/means of processing: the school |
| **Data Processor** | Entity processing on behalf of a fiduciary: SchoolOS |
| **Data Principal** | The person the data is about (for children, rights exercised by parents/guardians) |
| **Data Protection Board** | India's regulator under the DPDP Act; receives breach reports |
| **CERT-In** | Indian Computer Emergency Response Team; requires reporting of specified cyber incidents within 6 hours |
| **DPA** | Data Processing Agreement between school and SchoolOS |
| **DPIA** | Data Protection Impact Assessment |
| **ZDR** | Zero Data Retention: an API arrangement where the provider doesn't store prompts/outputs after responding |
| **Verhoeff checksum** | Check-digit algorithm used by Aadhaar numbers; SchoolOS uses it to detect and mask Aadhaar numbers in text |
| **Crypto-shredding** | Deleting encryption keys so remaining encrypted data (incl. backups) becomes unreadable |

| **BOLA** | Broken object level authorization: accessing objects by ID without permission |

| **Chunk** | A retrievable segment of a document with metadata and embedding |
| **DEK / KEK (CMK)** | Data encryption key (per tenant) / key encryption key held in KMS |

| **PITR** | Point-in-time recovery for databases |
| **RAG** | Retrieval-augmented generation: answering using retrieved content |
| **RLS** | PostgreSQL Row-Level Security: per-row access policies enforced by the database |
| **RPO / RTO** | Recovery point objective (max data loss) / recovery time objective (max downtime) |
| **RRF** | Reciprocal Rank Fusion: combining ranked lists by summing 1/(k + rank) |
| **Search result block** | Claude Messages API content block used to pass retrieved content with source/title so answers can cite it |
| **SLO** | Service level objective |
| **Step-up authentication** | Requiring fresh MFA before a sensitive action |

## Platform, deployment and billing

| Term | Meaning |
|---|---|
| **Control plane** | The part of SchoolOS that runs the business and the fleet: platform admin panel, billing, fleet registry. Runs only in the shared deployment; never reads student data (16) |
| **Data plane** | Everything that serves schools day to day: the shared tier's tenant app and every dedicated host |
| **Shared tier** | Default plan: the school is a tenant on the pooled multi-tenant platform in AWS Mumbai |
| **Dedicated tier** | Premium plan: the school gets its own isolated host (same software, one tenant), own storage and key, optional custom domain (ADR-0015) |
| **Deployment** | A place SchoolOS runs for a school: the shared stack or one dedicated host; listed in the fleet registry |
| **Heartbeat** | A signed message a dedicated host sends to the control plane every 5 minutes with version, health, backup state and counts, never personal data (16 §12) |
| **HMAC** | Hash-based message authentication code; proves a heartbeat came from the host that holds the shared key and was not changed |
| **Operator** | A SchoolOS staff member who uses the platform admin panel with a platform role (`platform_owner`, `platform_engineer`, `support_agent`, `billing_admin`, `platform_viewer`); not a school user |
| **Step-up (operators)** | Fresh MFA within 5 minutes before risky platform actions (marked ᴿ) |
| **Two-person rule** | An action (offboarding, emergency break-glass) that needs a second, different operator to approve |
| **MRR / ARR** | Monthly / annual recurring revenue: monthly-equivalent subscription income excluding GST and trials; ARR = MRR × 12 |
| **Trial / past due / suspended** | Subscription states: free period before paying; unpaid after the due date (15-day grace follows); access paused by a human decision (16 §9) |
| **GST** | Goods and Services Tax. Within one state: CGST + SGST (9% + 9% at the 18% rate); across states: IGST (18%) |
| **GSTIN** | 15-character GST identification number; its first two digits are the state code (Andhra Pradesh = 37) |
| **SAC** | Services Accounting Code printed on each invoice line |
| **Financial year (FY)** | Indian accounting year, 1 April to 31 March (e.g., FY 2026-27); invoice numbers restart each FY |
| **TDS** | Tax deducted at source: an amount a school may deduct from a payment and deposit with the tax department on SchoolOS's behalf |
| **UTR** | Unique transaction reference of a bank transfer (NEFT/RTGS/IMPS), recorded with a manual payment |
| **Custom domain** | A school's own web address (e.g., `office.<school>.edu.in`) pointing at its dedicated host |
