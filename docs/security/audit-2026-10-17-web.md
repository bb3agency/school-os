Web auditor of the 2026-10-17 wave, on branch `wip/audit-web` from `main` at `aaa6e0fd`. Scope: `apps/web`
(features, app routes, BFF in the browser and server), accessibility at 1366×768 and on phones, the
English-first rule (ADR-0036) and the dormant Telugu catalogue, client performance, test quality, and
consistency between docs/02, 03, 05, 09, 13, 14, 17 and the code. Backend security and backend business
logic belong to the other two auditors. R2-0 files (web `(public)` group, BFF public proxy, `/p/{token}`,
parent-language settings, `app/public/`, `app/core/languages.py`, `infra/db/bootstrap.sql`,
`app/core/rate_limits.yaml`) were not edited.

## Checked and clean (no finding)

- **BFF security** (beyond the 2026-10-04 audit): CSRF synchronizer token plus Origin and Sec-Fetch-Site on every unsafe BFF call and on `POST /bff/auth/session`; `__Host-` cookies, `HttpOnly`, `SameSite=Lax`, no `Max-Age` on sessions; traversal and encoded-slash refusal before the edge and platform checks; header allowlists both ways; `Location` rewritten or dropped; CSP nonce + `strict-dynamic`, no inline styles in production, `frame-ancestors 'none'`; sign-out redirect comes from the BFF's own JSON. No `any`, `dangerouslySetInnerHTML` or `style=` in `src/`.
- **Hard-coded strings**: none in product components (only the dev-only UI reference, `features/dev-ui`).
- **Idempotency keys**: every create/start-job POST the web app sends carries one (`useApiForm`, `ActionDialog`, PDF jobs, uploads).
- **Cache after mutations**: every `ActionDialog`/`useApiForm`/`useApiMutation` either invalidates its keys, navigates, or (Ask memory) settles optimistically.
- **School switch**: a full page load (`window.location.assign`), so no query cache crosses schools.
- **Print**: A4 `@page`, named landscape page for registers, chrome hidden, tables wrap inside the page, Telugu line height under `:lang(te)`.
- **Docs**: no broken relative links or anchors in docs/, CLAUDE.md, README, SECURITY, apps/web/README; every component in `components/ui` is in docs/17 §4; file paths named in docs/02, 03, 05, 09, 12, 13, 14, 17 exist except R2 files that are planned.

## Verification
