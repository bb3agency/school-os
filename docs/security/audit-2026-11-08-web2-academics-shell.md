## Verified clean (no finding)

- **Navigation by permission** (`components/shell/SchoolShell.tsx`): every item's permission
  matches the route's API permission (attendance `attendance.read`; marks any of `marks.read`,
  `marks.record`, `exam.manage`; readiness and portal calendar `dq.readiness.read`; promotions
  `tenant.structure.manage`, matching `students/api.py` promotions routes). Palette quick actions
  and the phone bottom bar use the same filter. Class teachers see only their sections because
  `GET /sections` is scoped by the API; the picker adds no other source.
- **Attendance**: IST "today" (`todayIst`), `max` on the date, statuses kept on a failed save
  (patchy network: the form state survives, `ApiErrorAlert` plus `ProblemList` show the 422 codes),
  read-only holders get disabled radios and no Save or import, `KEYS.attendance` invalidated after a
  save and an import, keyboard use through native radios in a fieldset per student, the
  segmented control fills the width on phones with 44 px targets (`pointer-coarse`).
- **Month register print**: A4 landscape through the named page `register-landscape`, table cells
  wrap and `.table-scroll` is `overflow: visible` in print, pickers and Save bar hidden.
- **Marks**: Idempotency-Key on exam creation, exams invalidated after create, grid invalidated after
  entry and import, phone layout keeps typed values across Previous/Next, `percent` and decimal
  strings match `MarksStudentOut` / `MarkOut`.
- **School home** (`features/school/HomeView.tsx`): each card is fetched only with its screen's
  permission; fees only for accountant and principal homes.
- **Shared formatters** (`lib/format.ts`): dates in the school format in IST, INR with lakh grouping
  and Latin digits, counts and bytes through `Intl` with `en-IN`.
- **Pagination** (`components/ui/Pagination.tsx`): polite live range, hidden in print, 44 px
  targets on touch.

## Outside my area

  namespace on their `ApiErrorAlert`); fine today because 422 codes go through `ProblemList`.
- Attendance saves do not invalidate insights (flags, timeline), which the API recomputes on its
  own schedule; insights belongs to another feature owner.
